## 1. Декодер ActionCodec принимает сумму, а не набор кодов ⭐

**Дата:** 13 авг 2026. **Как:** чтение кода, `third_party/actioncodec`.

```python
# actioncodec/modeling_actioncodec.py:271
z_q = self.vq.from_codes(indices)[0]      # [0] — это СУММА
# actioncodec/modeling_actioncodec.py:303
x_recon, padding_mask = self.decoder(z_q, embodiment_ids, durations)
```

`ResidualVectorQuantize.from_codes` (`actioncodec/rvq.py:403`) возвращает пару:

```python
z_q = 0.0
for i in range(n_codebooks):
    z_p_i = self.quantizers[i].decode_code(codes[..., i])
    z_p.append(z_p_i)
    z_q = z_q + self.quantizers[i].out_project(z_p_i)
return z_q, torch.cat(z_p, dim=-1), codes
```

В декодер уходит `z_q` — сумма. Конкатенация по уровням `z_p` не используется.

**Следствие, важное для плана.** Декодер не может знать, каким кортежем кодов
порождена сумма. Поэтому «нарушение остаточной семантики» на уровне декодера
не существует — нарушать нечего.

Проблема при этом **не исчезает, а переформулируется**: вопрос не «согласован
ли кортеж», а **не ушла ли сумма из области, на которой декодер обучался**.
При подмене кода грубого уровня со старым суффиксом сумма сдвигается на
`Δe = e₁(v) − e₁(c₁)`, и этот сдвиг может вывести её за пределы облака,
порождаемого кодировщиком.

А переквантизация суффикса из §4.1 плана — это в точности **проекция
предсказанной чистой латенты на достижимое множество сумм**, жадно по уровням.
Операция в пространстве латент; иерархия входит лишь как способ проекции.

**Что это значит для новизны.** Заявка «чиним остаточную семантику» не
проходит. Живая версия — измерительная и применимая ко всему семейству:

> итеративная и параллельная генерация над RVQ порождает кумулятивные латенты
> вне области кодировщика, и декодеры там деградируют

Это относится и к ResGen, и к ActionCodec-BAR, и к любому параллельному
генератору над RVQ, то есть находка про класс методов, а не про наш.

Оговорка: интерфейс `decode()` принимает **перемежающиеся** токены —
`[q0_t0, q1_t0, …, qN_t0, q0_t1, …]`. Учитывать при индексации.

## 2. Концентрация эффекта на первом токене

**Как:** подстановка всех кодов в одну позицию, замер сдвига декодированного
чанка (макс-норма по чанку, в долях размаха действий).

| | 1-я позиция | 2-я | 3-я | 4-я | остальные |
|---|---|---|---|---|---|
| VQ-VLA (RVQ, 4 уровня, словарь 256) | **53%** | 21% | 16% | 10% | — |
| OAT (FSQ, 8 регистров, словарь 1000) | **51%** | ~7% каждая | | | |

Межархитектурная инварианта: остаточное квантование против порядкового,
обученный словарь против регулярной решётки, 4 позиции против 8 — доля первой
та же. У OAT разброс между позициями семикратный.

**Зачем:** обоснование неравномерного распределения вычислений по уровням. И
довод в пользу потока против авторегрессии: АР фиксирует доминирующий токен
необратимо.

**Чего не следует:** что перераспределение бюджета по позициям что-то даст.
Это гипотеза, а не вывод.

**Не проверено:** переносится ли на ActionCodec-RVQ.

## 3. Геометрия кодов против пространства действий (FSQ)

**Как:** `experiments/c3_grid_vs_action.py`, OAT, 48 чанков, все 1000 кодов на
каждый из 8 регистров.

| величина | значение |
|---|---|
| соседи по решётке ближе по действию | **3.85×** медиана, **25.9×** на 1-м регистре |
| ложных соседей (близко по решётке, далеко по действию) | **0%** |
| ранговая связь глобально | 0.726 |
| она же внутри окрестности из 20 | 0.414 |

**Читать так:** на регулярной решётке FSQ близость кодов уже является
физической метрикой; считать её через декодер незачем. Крупный масштаб
передаётся хорошо, тонкий порядок внутри окрестности — плохо.

**Не проверено на RVQ.** Словарь обученный и нерегулярный, плотность кодов
неравномерна. Ответ может быть противоположным, и это kill-тест §7.1 плана.

## 4. Пол разрешения и локальность политики

| | OAT (FSQ) | VQ-VLA (RVQ) |
|---|---|---|
| минимальный достижимый шаг | 1.0% размаха | 3.4% размаха |
| p(жадного кода) у политики | 0.22–0.31 | 0.50–0.70 |
| доля пути от идеальной локальности к случайной | 13–24% | 35–44% |

Регулярная решётка даёт втрое более тонкий пол и втрое более локальную
политику. Политика OAT выучила геометрию решётки сама (ранговая связь
вероятностей с расстоянием 0.35–0.73), хотя софтмакс плоский, а индексация
смешанным основанием.

## 5. Лестница по префиксу (OAT)

Ошибка реконструкции при декодировании из `k` первых регистров, в долях
размаха: k=1 → 1.61%, k=2 → 1.23%, k=4 → 1.04%, k=8 → 0.88%.

Чистые ступени только на степенях двойки; **k=5 хуже k=4** — следствие
`token_dropout_mode: 'pow2'` в обучении OAT. Пример того, как деталь
обучения токенизатора проступает в его поведении.

## 6. Геометричная голова политики

**Как:** `experiments/head_geometric.py`, синтетика, без данных.

Шаг градиента понижает вероятность кода, выбранного самой головой. Меряется,
насколько дальше уходит освободившаяся масса по сравнению с пропорциональным
перераспределением, при уравненной уверенности (p(моды) = 0.25).

| голова | дальность | параметров |
|---|---|---|
| плоская (Linear→K) | **1.01** | 257 257 |
| факторизованная по координатам | 1.24 | 5 912 |
| смесь в латенте M=4 | **1.99** | 9 253 |
| смесь в латенте M=8 | **2.23** | 18 505 |

Плоская даёт ~1.0 как и требует теория — проверка реализации.

Развёртка по ширине компоненты при удержанной уверенности монотонна:
σ=0.2 шага решётки → 1.17, σ=1.0 → 1.47, σ=2.4 → 2.42. То есть σ — настоящая
ручка радиуса обобщения, и её надо калибровать, а не брать с потолка.

**Где пригодится здесь:** §12 плана отмечает, что жадная переквантизация
против усреднённой `ĥ` смажет моды. Смесевая голова в латенте — ответ на это,
и методика калибровки σ готова. Для RVQ шаг нерегулярен, калибровать заново.

## 7. Закрытые направления

Перечислены, чтобы не переоткрывать.

- **Локальность исследования у дискретных политик.** Управление масштабом
  достаётся бесплатно температурой по уровням (1.86×); голова добавляет сверх
  этого только локальность (1.65×), и то на VQ-VLA. На OAT политика уже
  локальна (13–24% пути), запас ~1.2×. Мало.
- **Геометричное ядро переходов в дискретном потоке.** Занято DFM-VLA:
  `p_t(x|x₁) = softmax(−β_t·d(x,x₁))` плюс Metric-Aligned Action Tokenizer,
  обучаемый триплетным лоссом. Абляции: LIBERO 98.0 полная / 96.7 без MAAT /
  93.5 без embedding-guided.
- **Иерархическая генерация над RVQ сама по себе.** Занято ResGen,
  SIEDD/HiCoDD, HiCoDiT, ActionCodec-BAR — все сохраняют иерархию через
  фиксацию грубого уровня.
